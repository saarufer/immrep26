# IMMREP26 — predicting which reported TCR–pMHC pairs validate

Kaggle competition [`immrep26`](https://www.kaggle.com/competitions/immrep26),
closes 2026-11-02 15:00 UTC.

Every TCR in the test set is already *reported* in VDJdb as recognising its
annotated peptide–HLA. The task is to rank them by whether that annotation
holds up in the Schumacher lab's standardised functional screen, where roughly
44% of re-tested pairs showed no reactivity. So this is not specificity
prediction against random decoys — it is **predicting annotation reliability
among historically reported positives**.

## What the competition actually measures

`test.csv` holds 2,636 paired αβ TCRs over 8 epitopes in one file, split by
Kaggle into two leaderboards:

| | epitopes | rows | role |
|---|---|---:|---|
| public | GILGFVFTL, YLQPRTFLL, TTDPSFLGRY, NLVPMVATV, GLCTLVAML | 2,034 (1,782 scored) | labels published via TCRvdb → **this is the training set** |
| private | CINGVCWTV, LLWNGPMAV, LTDEMIAQY | 602 | decides the final ranking |

The metric is **mean per-epitope ROC AUC with ambiguous rows dropped**,
reverse-engineered from the organisers' baseline file and then confirmed
end-to-end: a submission predicted locally at 0.8396 scored 0.839. Only the
ranking *within* an epitope is read, and each epitope carries equal weight
regardless of size. `src/immrep/metric.py` documents the candidate metrics that
were ruled out.

Two consequences worth internalising:

- A near-perfect public score is a label join, not skill. Public standing is
  not worth optimising.
- With three private epitopes of ~213/201/114 scored rows, the standard error
  of the private score is about **0.023**. Leaderboard gaps below ~0.05 are
  noise.

## Findings

`reports/02_signal_landscape.md` is the main document. In short: validated TCRs
sit in tight, label-pure clusters and non-validating ones are isolated, so
every method is really answering "is this TCR part of a convergent,
antigen-driven cluster". That signal is one-dimensional and saturates.

| approach | mean per-epitope AUC |
|---|---:|
| organisers' tcrdist3 baseline | 0.8247 |
| organisers' AlphaFold3 min-PAE baseline | 0.787 |
| **rank-averaged SCEPTR kernel density (current best)** | **0.8415** |

Eight things that do *not* help, each with a mechanism in the report: VDJdb
annotation metadata (actively harmful — `vdjdb_score` scores 0.455 and flips
sign between epitopes), OLGA generation probability, the choice of
representation, background-density normalisation, cluster-shape features,
supervised fusion, graph centrality and label propagation, and an
unseen-epitope specificity model (0.481, below chance).

Because five epitopes cannot support a fitted combiner — logistic regression on
top of density loses 0.006, gradient boosting loses 0.021 — **any fusion is a
zero-parameter rank average**, and a component only enters if it adds >0.02 in
leave-one-epitope-out. That rule is enforced in `scripts/12_final_fusion.py`.

## Layout

```
src/immrep/      metric, data loading, features, LOEO harness, submission QC
scripts/         numbered, each runnable standalone, 00 → 12
reports/         findings, regenerated by the scripts that produced them
data/            all gitignored; see data/external/README.md for provenance
```

Validation is leave-one-epitope-out throughout. Random splits leak badly here:
near-identical clonotypes sit on both sides of a random split.

## Reproducing

```bash
uv venv --python 3.12 .venv && source .venv/bin/activate
uv pip install torch --index-url https://download.pytorch.org/whl/cu128
uv pip install numpy pandas scipy scikit-learn lightgbm tcrdist3 sceptr kaggle biopython
./scripts/00_fetch_external.sh            # VDJdb; TCRvdb must be requested
kaggle competitions download -c immrep26 -p data/raw && unzip data/raw/immrep26.zip -d data/raw
python scripts/02_confirm_metric.py       # reproduces the metric derivation
python scripts/05_sceptr_embeddings.py
python scripts/12_final_fusion.py          # the submission decision
```

Structure prediction (`scripts/08`–`10`) needs `boltz`, which pins `numpy<2`
and so conflicts with `pyarrow`; interim files are CSV to avoid the clash.
Folding all 2,636 complexes takes ~10 h on an RTX 5090 at 14 s each.

## Data terms

TCRvdb is request-only from [tcrvdb.nkiai.nl](https://tcrvdb.nkiai.nl) and its
terms **prohibit redistribution**, so it is gitignored and never committed.
Work using it must cite [doi:10.1016/j.immuni.2026.09.007](https://doi.org/10.1016/j.immuni.2026.09.007).
VDJdb carries its own CC-BY-NC-SA terms.
